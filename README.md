# Alvorada Experimental Workbench

This repository is a writable experimental destination for bounded Alvorada/ODEX workstreams. Historical Alvorada archive material remains in `titanicprime/alvorada-archive` and is used only as reference unless explicitly migrated through review.

Current work is experimental and does not establish institutional adoption, production authentication, deployment approval, certification, compliance, or independently verified real-world effects.
